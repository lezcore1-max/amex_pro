# American Express Campus Challenge 2026 - Round 1

This repository contains our team's solution for the AmEx Campus Challenge 2026 (Round 1). 
The core objective of this challenge is to "Measure Customer Profitability of Premier Product" using an unsupervised dataset of 500,000 cardmembers and 23 anonymized features.

## Evolution of Our Approach

We tackled this unsupervised ranking problem using two distinct methodologies:

### Version 1: The Business Logic P&L Model
Initially, we built a highly rigorous, economically defensible Profit & Loss framework (`pipeline_phases_b_to_f.py`). We estimated raw dollar revenues and costs by applying real-world assumptions (e.g., 18% APR on Revolve Balance, 2% Interchange on Spend, 60% Loss Given Default).

While financially sound, this approach scored **~0.519** on the leaderboard. The leaderboard's top scores (~0.94) strongly implied that the ground truth labels were not derived from a complex, subjective financial model, but rather from a cleaner, more deterministic algorithmic pattern.

### Version 2: The Data-Driven PCA Model (Current)
To close the gap, we pivoted to a purely data-driven approach (`pipeline_data_driven.py`) that eliminates all subjective human assumptions and financial constants.

1. **Feature Selection:** We isolated the fundamental drivers of a credit card: `f1` (Revolve), `f5` (Spend), `f4`, `f21` (Rewards), `f11` (Risk), and `f17` (Credit Line).
2. **Standardization:** We Z-scored all features to remove arbitrary dollar weightings and unit disparities.
3. **Principal Component Analysis (PCA):** We used PCA to find the single axis of maximum variance (PC1) that best separates the data. In unsupervised financial datasets, this primary component naturally captures the core bimodality between high-value engaged users and low-value users.
4. **Scoring:** The profitability score is generated by ranking this principal component.

## File Structure

- `pipeline_data_driven.py` — The V2 (PCA) pipeline that generates the final predictions.
- `pipeline_phases_b_to_f.py` — The legacy V1 (Business Logic) pipeline.
- `spotcheck_v2.py` / `phase_a_audit.py` — Data auditing and verification scripts used during exploration.
- `amex_analysis_notebook.py` — Exploratory data analysis scripts.

## How to Run

Ensure you have the dataset `campus_challenge_r1_data.csv` in the root directory (it is ignored by git due to size).

```bash
python pipeline_data_driven.py
```
This will output `amex_submission_round1_v2.xlsx` containing exactly 500,000 rows with predictions ranked between 0 and 1, ready for submission.
